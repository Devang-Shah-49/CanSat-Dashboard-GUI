# DJS Arya GUI

## Description

### URL:- <http://localhost:5000>

## Installation

```cmd
npm i
touch .env
mkdir csv_files
```

## Dependencies

### .env Contents

```plain-text
TEAM_ID = <TEAM_ID>
PASSWORD = <PASSWORD>
COM_PORT = <COM_PORT>
```

### Requires [Tile Server](https://github.com/Ronnit3012/ARYA-Tile-Server) To Be Running

## Run

```cmd
npm start
```
